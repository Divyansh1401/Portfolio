# Kinko Logo Explorations — 25 Concepts Across 5 Directions

> Gallery for gut-pick review. Each concept is intentionally a sketch, not final art.
> Brand colors used throughout: green-500 `#009b1a`, navy-500 `#0b2b40`, navy-900 `#02090d`, green-50 `#e6f5e8`, green-800 `#003e0a`.
> Open in a Markdown viewer that renders inline SVG (VS Code preview, GitHub, Obsidian).

**How to read each concept:**
- One-liner — what it is
- Geometry — composition rules
- Color use — green-led / navy-led / dual / mono
- Sketch — rough visual intent
- Strengths / Weaknesses — honest trade-offs
- Brand-fit — self-rated 1–5 against KT Section 16

## Direction A — Clarity Lens
*Insight, focus, decoding complexity. Visual metaphors of seeing, resolving, and bringing things into view.*

### A1 — Concentric Resolve
**One-liner:** Three faded concentric circles converging onto a solid green core — chaos resolving into clarity.
**Geometry:** Outer rings at 25% / 50% / 85% opacity navy. Center: solid green disc, ~13% of total diameter.
**Color use:** Navy-led, green core.
**Sketch:**
<svg viewBox="0 0 120 120" width="120" height="120" xmlns="http://www.w3.org/2000/svg"><circle cx="60" cy="60" r="50" fill="none" stroke="#0b2b40" stroke-width="2" opacity="0.25"/><circle cx="60" cy="60" r="36" fill="none" stroke="#0b2b40" stroke-width="3" opacity="0.55"/><circle cx="60" cy="60" r="22" fill="none" stroke="#0b2b40" stroke-width="4"/><circle cx="60" cy="60" r="8" fill="#009b1a"/></svg>

**Strengths:** Universally understood "focus" metaphor; works at any size; reverses cleanly.

### A2 — Aperture Frame
**One-liner:** A thick rounded-square outline housing an offset green inner square — a lens with its aperture showing.
**Geometry:** Outer rounded-square frame (`radius-20`-equivalent), 6px stroke; inner solid green square (`radius-12`-equivalent), centered.

### A3 — Two-Lens Overlap
